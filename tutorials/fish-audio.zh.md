# Fish Audio：克隆语音、一个免费模型、逐词高亮

[English](fish-audio.md) · **简体中文**

[Fish Audio](https://fish.audio) 是一个语音克隆服务：上面的每个语音都是用一段简短的录音做出来的——用户做的，或者你自己做的——它现在的模型 S2.1 Pro 会说 83 种语言。插件的 **Fish Audio** 那一节只用一个 API 密钥就能连上它，朗读用这些语音时也逐词高亮，和用 Azure、Kokoro 的语音一样。这一页讲：密钥、什么免费什么收费，以及一个语音怎么进到播放器里。

## 密钥

> **国内网络**——api.fish.audio 是走 Cloudflare 的；网上有第三方反馈说，从国内直连有时要挂代理，但我们没有实测过，这里不打包票。

1. 到 [fish.audio](https://fish.audio) 注册，打开控制台的 **API** 那一节。
2. **API Keys** → 建一个，起个名字，抄下来。
3. 在 Zotero 里，**编辑 → 设置 → Zotero-TTS → Fish Audio**，**云端（api.fish.audio）**这一块：把它粘进 **API 密钥**，点**测试连接**，再点**启用**。

## 免费或付费

这一块的**只用免费模型**开关默认是开着的。

- *开*——每句话都用免费的 S2.1 Pro 读，账户不需要余额。用 Fish Audio 自己的话说，它的条款是：文本量不限，不保证速度，你发的文本可能会被留下用于改进模型。这原本是限时优惠，已经延长过不止一次，也可能随时结束。
- *关*——走付费的 S2.1 Pro：同一个模型，每百万字节文本 15 美元，大约 18 万个英文单词；一个汉字算三个字节。费用从账号的 **API 余额**（控制台 → **Billing**）里扣，这个余额和网站上的点数是分开的。没有余额时，**测试连接**会显示 *Insufficient API credit*，在你充值或者把免费模型重新打开之前，都不会出声。

## 语音

语音在播放器里属于**本地**语音模式，写成 `Fish-cloud-<name>`。三个来源开关默认开启，彼此独立。

- **官方语音。** 自动列出 **Fish Official** 发布的语音。社区语音只有在你自己输入其 Model ID 后才会加入。
- **我的语音。** 自动列出你的 Fish Audio 账户创建的语音，无需粘贴 ID。
- **手动语音。** 提供**语音（Model IDs）**中填入的语音。关闭此开关会隐藏它们，但不会清除已保存的 ID。
- **语音（Model IDs）。** Fish Audio 将每个音色的标识称为 Model ID。点击字段标签里的 **Model IDs** 即可打开 [Fish Audio 音色发现页](https://fish.audio/app/discovery/)。找到语音，复制其 Model ID 并粘贴到这里。多个用逗号或空格分开。字段旁的 **?** 会提示这个页面。以前粘贴的语音链接仍然有效。要编辑此字段，先**停用**云端块，修改后再**启用**。
- **更改来源。**先**停用** Fish Audio，解锁来源选项，修改后再**启用**。如果有朗读播放器打开，停用时会先询问是否停止朗读。重复的语音只显示一次，只要仍有一个已开启的来源提供它，就会继续列出。
- **语言。** 语音按语言分组，列出多种语言的归在*多语种*下。明确标注了地区口音的英语语音会单独分组，例如英语（美国）、英语（英国）和英语（印度）。未标注地区的仍归在英语下。
- **Default。** 即使三个来源都关闭，模型自带的声音也始终可选。
- **更新列表。**点击**启用**或**测试连接**会重新获取 Fish Audio 语音列表。重复打开时会复用已加载的列表，直到 Zotero 重启。列表更新失败时，会保留上次成功的语音并提示；更换 API 密钥不会复用另一个账号的列表。

**测试连接**会统计列出的语音数量，并检查模型能否发声。手动输入的语音如果页面已删除，会显示为 *(not found)*，直到你移除其 ID。

## 值得知道

- *一句话大约两秒钟送达*，一次朗读里的第一句会久一点；播放器会提前取，所以读起来是连续的。
- *特别长的一段*——没有句号的一整段、当成一句话来读的表格——花的时间按比例变长：一分半钟的语音大约要四十秒送达。
- *发送的内容*是正在读的这句话，以及语音的 id。
- *速度*是播放器自己的滑块，跟其他语音一样；不会重新生成。
