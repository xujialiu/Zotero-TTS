# 用 Azure Speech 的免费额度

[English](azure-speech-free-tier.md) · **简体中文**

Azure AI Speech 就是插件里的 **Azure** 服务商：一百多种语言、几百个神经网络语音，其中的多语种语音能一口气读完中英混排的文档，而且带词级时间戳——所以朗读能逐词高亮。它的**免费（F0）定价层**每月给 **50 万字符的神经网络语音合成**，月月都有，只要这个资源还在就一直有。一篇期刊论文 4 万到 8 万字符，也就是每月六到十二篇，整篇读完，不花钱。本教程带你在这个层上拿到密钥，并填进插件。耗时约十五分钟，大部分花在微软的注册上。

## 你需要什么

- 一个微软账号（任何 Outlook/Hotmail/Xbox 登录名，或者注册时新建一个）。
- 一张信用卡或借记卡，用于 Azure 注册。微软拿它验证身份；免费层不扣费，免费账户也不会自动升级成付费，除非你自己去升。学生可以改用 [Azure for Students](https://azure.microsoft.com/free/students/)，用学校邮箱，不需要卡。
- 插件 1.0 或更新的版本。

> **国内网络**——一定要注册**全球版** Azure（azure.microsoft.com）。插件访问的是 `<区域>.tts.speech.microsoft.com`，而由世纪互联运营的 Azure 中国（azure.cn）是另一朵云，终结点也不同，它的密钥在插件里用不了。注册全球版通常需要一张能付外币的信用卡（Visa/Mastercard），或者用教育邮箱走上面的 Azure for Students。

## 1. 注册 Azure 账号

打开 [azure.microsoft.com/free](https://azure.microsoft.com/free/)，点**免费开始使用**（Start free）。用微软账号登录，填资料，验证手机号和银行卡。免费账户还附带头 30 天 200 美元的额度和十二个月的若干免费用量——这些插件都用不上：下面的语音免费层是永久的，和它们无关。

## 2. 在免费层上创建语音资源

1. 打开 [Azure 门户](https://portal.azure.com/)，选**创建资源**（Create a resource，左上角的 **+**）。
2. 在应用市场里搜 **Speech**，选微软的 **Speech**（在 Azure AI services / Foundry Tools 底下——这一族的名字每年都变，产品没变）。点**创建**。
3. 填表：

   | 字段 | 填什么 |
   |---|---|
   | 订阅 | 注册时创建的那个（*免费试用* / *Azure subscription 1*） |
   | 资源组 | **新建**，名字随意（`zotero-tts`） |
   | 区域 | 离你近的一个——见下 |
   | 名称 | 任何不重名的（`zotero-tts-speech`） |
   | 定价层 | **免费 F0** |

   每个订阅在每个区域只能有一个免费语音资源；如果 *Free F0* 是灰的，说明你在那里已经有一个，或者曾经有过：删掉的资源会在软删除状态里滞留一段时间，仍然占名额。换一个区域，或者去清除它（Azure AI services → 管理已删除的资源）。
4. **查看 + 创建**，再点**创建**。部署不到一分钟；然后点**转到资源**。

### 选哪个区域

区域就是为你的请求提供服务的地方，选近的延迟低：东亚选 `eastasia`（香港）或 `japaneast`，欧洲选 `westeurope` 或 `northeurope`，北美选 `eastus` / `westus2`。几乎每个语音在每个区域都有；完整名单见[语音服务区域](https://learn.microsoft.com/azure/ai-services/speech-service/regions)。插件要的是区域的短 id（`eastasia`，不是 *East Asia*）；资源页面上就写着。

## 3. 抄下密钥和区域

在资源页面里打开**密钥和终结点**（Keys and Endpoint，在左栏的*资源管理*下）。那里有 **KEY 1**、**KEY 2** 和**位置/区域**。抄下 KEY 1，记住区域 id。两个密钥都能用；有两个是为了轮换其中一个时另一个还在用。

## 4. 把插件指过去

Zotero → 设置 → Zotero-TTS → **Azure** 那一节：

| 字段 | 填什么 |
|---|---|
| 启用 Azure 语音 | 开 |
| API 密钥 | KEY 1 |
| 区域 | 区域 id，例如 `eastasia` |

**测试连接**应当回答 `Connected. N voices available. Synthesis works.`——测试会合成两个字符，证明这个密钥不只能列语音，还能真的花额度。打开朗读，语音模式选*本地*，`Azure-…` 那些语音就在那里；读单一语言的文档就选该语言的语音（`Azure-晓晓`、`Azure-Ava`），中英混排的文档就在「多语言」条目下选一个 *Multilingual* 的。要逐词高亮，把*设置 → 常规 → 朗读 → 高亮当前*设成**单词**。

## 免费层包含什么、不包含什么

- **每月 50 万字符**的标准神经网络语音——也就是插件列出的那些 `…Neural` 语音，多语种的也算在内。计数每月 1 日重置。
- 不包含：HD 语音（名字里带 `…:DragonHD…`）是另一条付费产品线；免费资源上就用普通的神经网络语音。
- **每分钟 20 个请求**。插件每句发一个请求，并提前预取几句。正常阅读远在限额之下，但连着一串很短的句子（参考文献表、表格）就可能超；Azure 这时回 429，朗读会带着配额提示停下。要是常遇到，把*设置 → Zotero-TTS → 朗读*里的*预取*降到 1 或 2，或者再按一次播放。
- 当月额度用完后，Azure 会拒绝后续请求，直到下月 1 日；在插件里表现为密钥被拒。想接着读，就把资源的定价层改成**标准 S0**（*资源管理 → 定价层*）：按量付费，神经网络语音大约每一百万字符 15 美元——一篇论文一美分上下。当前价格见[定价页](https://azure.microsoft.com/pricing/details/speech/)。
- 已经用了多少，在资源的**指标**（Metrics）页面上看（*Synthesized Characters*，按月求和）。只有正文计费：插件给每句话套的标记不计费。

## 疑难解答

- **「服务器拒绝了 API 密钥」**：密钥抄错了，或者区域字段填的不是这个资源的区域（`eastasia` 填成了 `eastus`）；也可能是当月额度用完了，见上。
- **「无法连接」**：到 `<区域>.tts.speech.microsoft.com` 没有路由——防火墙或者代理的问题；Zotero 走系统的代理设置。
- **没有我的语言的语音**：插件列的是这个区域提供的；几乎所有语音到处都有，但少数几个分区域。到[语音库](https://speech.microsoft.com/portal/voicegallery)里查一下这个语音，必要时在另一个区域再建一个资源。
- **读到一半，朗读带着「配额」停了**：上面说的每分钟 20 个请求，或者当月字符用光了。
