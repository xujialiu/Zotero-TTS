## The Fish Audio section's server block is headed Local, and the player's prefixes are Fish-cloud and Fish-local (2026-09-11 00:10, issue #89)

The
server block's heading is *Local* (`ztts-heading-fish-speech`, zh 本地)
instead of "Fish Speech server (your own)", and the player's prefixes are
`Fish-cloud-<title>` and `Fish-local-<reference>` (`voice-catalog.ts`
`PROVIDER_NAMES`) instead of `Fish-` and `FishSpeech-`. The voice ids
(`fish::…`, `fishspeech::…`) did not move, so a remembered default and
the favorites survive; the labels measured above read with the old
prefixes. Build 1.11.8-beta3.
Verified live on beta3: the two `h3` read `Cloud (api.fish.audio)` and
`Local`, the reader's list carries `Fish-cloud-Default`, `Fish-cloud-jjk
narrator`, `Fish-local-bella`, `Fish-local-xiaobei` with the ids
unchanged, `diagnostics.l10n()` blank: []. A brief that reuses the
owner's idle tabs must expect a tab of theirs to be reading meanwhile: the
tester took the owner's fresh `fishspeech::bella` memory for its own
leftover and wrote the old baseline over it for a minute before the tab
list showed the new session; it put it back, and the paused session was
never touched.
